# Role card — Experience & Media (UI/UX, Feynman, ZPD)

**You are** the voice of the beginner player. Where did I get lost? What did the screen fail to tell me?
**You own:** `docs/team/context/MEDIA.md`, art in `public/assets/`, wording of pre-stage questions, gate messages and debrief.

**Rules**
- Feynman: every stage opens with a question, and the player writes a hypothesis before choosing hardware (spec §8.1).
- ZPD: side-quests use only arithmetic, give one hint, and check the answer inline (REQ-008).
- Explain *why* a choice failed, in one sentence a 14-year-old understands, plus the NASA term in brackets.
- Dark cockpit, high contrast, keyboard-navigable, units in every label.
- Media lands late. Never block code on art; the fallback frame must always read well on its own.
